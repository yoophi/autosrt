# AutoSRT 2026.10.0

YouTube 영상 또는 로컬 미디어의 음성을 로컬 Whisper 엔진으로 인식해 SRT 자막을 생성하는 첫 릴리스입니다.

## 설치

```sh
brew install yoophi/tap/autosrt
autosrt config set model /path/to/ggml-small.bin
autosrt doctor
autosrt example.mp3
```

사전 빌드 바이너리는 macOS 15 이상 Apple Silicon용입니다. GGML 모델은 별도로 준비해야 합니다.

## 주요 기능

- YouTube URL과 로컬 오디오·비디오 입력 지원
- ratatui 진행 화면, 전체 출력 기록, 수동 스크롤과 자동 따라가기
- 언어·모델 기본값 저장과 `doctor` 의존성 진단
- 기존 출력 파일 보호, 취소와 자식 프로세스 정리
- GPU 초기화 실패 시 CPU로 한 번 재시도
- 기존 ystt 설정·모델을 복사하고 모델 경로를 갱신하는 `autosrt config migrate`

## 이전 및 제한

기존 ystt 사용자는 `autosrt config migrate`를 실행하세요. 원본 파일은 보존되며 새 설정이 이미 있으면 덮어쓰지 않습니다. `YSTT_MODEL`·`YSTT_CONFIG_DIR`은 호환 지원합니다.

여러 파일 배치 처리와 다운로드 중 전사는 설계 단계이며 이 릴리스에는 포함되지 않습니다. doctor는 실제 다운로드·전체 모델 로딩·GPU 호환성까지 검증하지 않습니다.

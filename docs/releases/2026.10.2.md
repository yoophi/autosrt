# AutoSRT 2026.10.2

YouTube 자동생성 자막을 음성 전사보다 먼저 활용하고, 소스 우선순위를 저장하거나 두 결과를 비교할 수 있습니다. 에이전트용 도움말과 오류 설명도 정리했습니다.

## 설치 및 업데이트

```sh
brew update
brew upgrade yoophi/tap/autosrt
autosrt --version
autosrt --help
```

처음 설치한다면 `brew install yoophi/tap/autosrt`를 사용하세요. 사전 빌드 바이너리는 macOS 15 이상 Apple Silicon용입니다. `command -v autosrt`로 실제 실행 경로를 확인하세요. `~/.local/bin`의 수동 설치본은 Homebrew 버전보다 먼저 실행될 수 있습니다.

## 자막 소스 선택

```sh
autosrt URL --language ko --subtitle-mode auto-only
autosrt URL --language ko --subtitle-mode auto-first
autosrt URL --language ko --subtitle-mode both --output result.srt
autosrt config set subtitle-mode auto-first
autosrt config get subtitle-mode
```

- `auto-first`: 자동자막 우선, 없거나 실패하면 전사합니다.
- `transcribe-first`: 전사 우선, 도구·모델 검증이나 처리 실패 시 자동자막을 시도합니다.
- `both`: 자동자막을 확인한 뒤 전사하고 `.auto.srt`, `.transcribed.srt`로 분리합니다. 자동자막 부재는 경고 후 전사 파일 하나로 성공합니다. 소스 처리 실패는 오류입니다.
- `auto-only`: 자동자막만 다운로드합니다. 없거나 실패하면 종료합니다.
- `transcribe-only`: 이전처럼 음성 전사만 수행합니다.

## 동작 변경과 이전 안내

**옵션과 저장 설정이 없을 때 YouTube 기본 동작이 전사에서 `auto-first`로 변경됩니다.** 이전 동작을 유지하려면 `autosrt config set subtitle-mode transcribe-only`를 실행하세요. 우선순위는 CLI 옵션 → 저장 설정 → `auto-first`입니다. 로컬 입력은 `auto-only`를 제외한 모든 모드에서 전사 하나만 수행합니다.

자동자막 다운로드 성공 시 Whisper 모델은 필요하지 않습니다. SRT로 제공되지 않는 자막은 FFmpeg를 통해 변환합니다. 업로더의 수동 자막은 대상이 아니며, 반복·겹침을 포함한 다운로드 자막의 내용과 시간을 유지합니다.

성공 stdout은 파일당 경로 한 줄입니다. `both`는 최대 두 줄이므로 스크립트에서 이를 처리해야 합니다. 소스는 파일 접미사로 구분하세요. 결과는 준비가 끝난 뒤 파일별로 저장하며, 두 파일 전체의 트랜잭션은 아니므로 늦은 저장 오류나 취소로 첫 파일만 남을 수 있습니다.

`--language`와 저장 `lang`은 자동자막 트랙과 전사 원음에 동일하게 적용됩니다. `both`에서 서로 다른 언어를 원하는 경우 별도 명령과 출력 경로를 사용하세요. 자동자막의 `auto`는 원본 트랙 선택, 전사의 `auto`는 초기 음성 언어 감지입니다.

## 도움말 및 검증

도움말에 설정 우선순위, 모드별 처리·출력·실패 조건, fallback 경계와 실제 허용 언어 코드 목록을 명시했습니다. `config set`의 잘못된 설정값은 종료 코드 1, CLI 해석 오류는 2임을 구분합니다. `doctor`는 자동자막 전용이 아닌 전체 전사 환경을 검사합니다.

42개 테스트, fmt/clippy 및 릴리스 빌드를 검증했습니다. 실제 한국어 자동자막 다운로드가 모델 없이 성공했고, 별도 세션 재점검에서 998구간의 SRT가 yt-dlp 결과와 바이트 단위 일치함을 확인했습니다. 기존 SIGPIPE 수정 회귀 테스트를 포함합니다. 일부 환경의 GPU 초기화 실패는 CPU 재시도로 처리하며, GPU 문제 자체나 한 파일 안의 언어 전환·배치·스트리밍 전사는 이번 변경 범위가 아닙니다.

# AutoSRT 2026.10.1

Whisper의 손상된 UTF-8 출력으로 전사가 SIGPIPE와 함께 중단되는 문제를 수정하고, AI 에이전트용 CLI 도움말을 보강했습니다.

## 변경 내용

- 자식 프로세스 stdout/stderr를 바이트 단위로 읽어 잘못된 UTF-8 로그가 출력 파이프를 조기에 닫지 않도록 수정했습니다.
- 전사 JSON에 손상된 UTF-8이 있으면 `�`로 대체하고 TUI 또는 stderr에 경고합니다. 해당 자막은 수동 교정이 필요합니다. JSON 구조 오류는 계속 실패로 처리합니다.
- `autosrt --no-tui URL` 및 `autosrt --no-tui FILE` 사용법, stdout/stderr 계약, 종료 코드, 설정 우선순위와 재시도 지침을 도움말에 명시했습니다.
- 모델 환경변수의 실제 값이 도움말에 노출되지 않도록 했습니다.
- 원본 음성 언어와 번역 언어의 차이, 혼합 언어 영상의 제약을 문서화했습니다.

## 설치 및 업데이트

```sh
brew update
brew upgrade yoophi/tap/autosrt
autosrt --version
autosrt --help
```

처음 설치할 때는 `brew install yoophi/tap/autosrt`를 사용하세요. `~/.local/bin/autosrt`가 PATH에서 먼저 발견되면 수동 설치본이 실행되므로 `command -v autosrt`로 확인하세요.

사전 빌드 바이너리는 macOS 15 이상 Apple Silicon용입니다. GGML 모델은 별도로 준비해야 합니다. 설정 이전이나 명령 변경은 필요하지 않습니다.

## 검증 및 제한

31개 테스트, cargo fmt/clippy 및 release 빌드를 통과했습니다. 실제 손상 로그/JSON 재생에서 기존 SIGPIPE를 재현했으며 수정본은 75개 자막을 생성했습니다. stdout, stderr, 1바이트 분할 출력과 GPU 실패 후 CPU 재시도 경로를 검증했습니다. 61분 전체 음성의 재전사를 완료한 검증은 아닙니다.

일부 환경의 Metal 셰이더 초기화 문제 자체는 해결하지 않았으며 CPU 자동 재시도를 유지합니다. 한 파일 안의 언어 전환, 배치 처리 및 다운로드 중 전사는 지원하지 않습니다. `--language`는 원본 음성의 언어이며 번역할 언어가 아닙니다.
